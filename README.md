# Lantern

Lantern — a customizable, fast web browser.

This repository contains an initial Electron-based scaffold to start building Lantern.

Goals and highlights
- Fast and lightweight browser shell
- Highly customizable UI and behavior
- Quick access: "Open GitHub from anywhere"
- App store / quick install placeholder to add web apps

Run (development)

1. Install dependencies:

   npm install

2. Start Lantern:

   npm start

What's included
- Electron main process (main.js)
- Preload bridge (preload.js) exposing small APIs to renderer
- Minimal renderer UI (index.html + src/renderer.js)
- TODO list for next features

Contributions welcome — see TODO.md and open issues/PRs.
